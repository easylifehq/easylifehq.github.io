# EasyLife One-Week Phone Field Test

## Goal

Use EasyLife on your phone for one normal week and write down what actually gets in the way.

This is not a full product audit. The point is to catch the moments where the app feels annoying, fake, too slow, too wordy, too suite-like, or not helpful enough.

Live AI provider testing is parked until after this week unless explicitly resumed.

## Routes To Use

Open these on your phone:

- Today: `/app/hq`
- Inbox: `/app/easylist/add`
- Plan: `/app/easycalendar/day`
- Notes: `/app/easynotes`
- People: `/app/easycontacts`
- Settings: `/app/settings`

## Simple Daily Loop

1. Open Today once in the morning.
2. Capture one loose thought in Inbox.
3. Check Plan when you need to decide what fits today.
4. Save or review one note/context item if something matters later.
5. Use People when a person/place thought comes up.
6. Write down every annoyance as soon as it appears.

## What To Look For

- Annoying names: labels that still feel like old `Easy*` modules, dashboards, or internal tools.
- Too much friction: too many taps, too much scrolling, confusing buttons, or unclear next steps.
- Missing capture paths: moments where you wanted to put something somewhere and could not tell where it belonged.
- Where AI would actually help: places where a suggestion, grouping, rewrite, or "what should I do next?" read would be genuinely useful.
- Save confusion: any moment where you are unsure whether something saved, stayed a draft, or did nothing.
- Phone layout issues: clipped text, cramped buttons, weird menus, horizontal scrolling, bad spacing, or giant cards.
- Module sprawl: moments where it feels like separate apps instead of one assistant.

## Notes Template

Copy one block whenever something stands out.

```text
Date/time:
Route:
What I was trying to do:
What annoyed me:
What I expected:
What happened instead:
Was I confused about saving? yes/no
Would AI help here? yes/no
If yes, what should it do?
Phone/layout issue? yes/no
Screenshot taken? yes/no
Severity: tiny / annoying / blocks use
```

## End-Of-Week Questions

- Which route did I actually use most?
- Which route did I avoid?
- What felt most like a real assistant?
- What still felt like old module sprawl?
- Where did I wish AI could read context and help?
- Where did I not trust the app?
- What one fix would make me more likely to keep using it next week?

## Parked During Field Test

- Live AI provider calls
- Broad chat assistant behavior
- Email/text sending
- Notification scheduling
- Calendar sync
- Real memory claims
- Geocoding or device location
- Hidden writes or automatic saves
