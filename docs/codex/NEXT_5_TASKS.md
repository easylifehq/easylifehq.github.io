# EasyLife Next 5 Tasks - Stage 9 Visual Polish

First screen rule: the login/public first viewport must read as EasyLife the assistant, not a catalog of EasyHQ, EasyList, EasyNotes, and other products. Remove/simplify requirement: remove or demote one visible product-inventory element such as "Explore products," "Products," or a row of Easy* product names. Guardrails: frontend copy/UI only; no route deletion, backend, auth provider changes, payments, Firebase rules/config, dependencies, package files, deploy config, generated output, secrets, or real AI promises.
